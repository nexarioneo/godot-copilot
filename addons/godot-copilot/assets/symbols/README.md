# Bundled icons

- Curated Material Symbols (Rounded style, 24px, single color) used by the
  plugin's Material 3 component library (`src/ui/md3/`).
- Source: Google Material Symbols (https://fonts.google.com/icons), fetched
  from the public release CDN used by Google Fonts.
- License: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).
- Files use a white fill (`#FFFFFF`) so components can tint them via theme
  colors.
- Currently the default (FILL=0) variant is bundled; selected/active states are
  expressed with token colors until dedicated FILL=1 variants are added.
