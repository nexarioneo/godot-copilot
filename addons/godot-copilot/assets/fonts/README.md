# Bundled fonts

- `Roboto-Regular.ttf` (weight 400) and `Roboto-Medium.ttf` (weight 500):
  Roboto by Google, taken from the official source repository
  (https://github.com/googlefonts/roboto, `src/hinted/`).
- License: Apache License 2.0, see `LICENSE.txt` in this folder.

Used by the Material 3 component library (`src/ui/md3/`). Code blocks and tool
arguments keep using the editor monospace font.
